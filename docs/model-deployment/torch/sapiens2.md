# Sapiens2 on PyTorch

## 模型简介

Sapiens2 人体分割，输入 1024×768，FP16。吞吐用 `torch.compile`。

规格：`0.4b`、`0.8b`、`1b`、`5b`。硬件：BW1100。一次用 1 张卡。

## 环境

| 项目 | 值 |
| --- | --- |
| 容器 | `sapiens2` |
| 镜像 | `10.16.1.152:5000/jenkins/model_test_env/vllm:0.28.1rc1-ubuntu22.04-dtk2610-py3.12-20261019-0127` |
| Python | 3.12.12 |
| PyTorch | 2.11.0 |

模型代码从 [facebookresearch/sapiens2](https://github.com/facebookresearch/sapiens2) 克隆。权重按 [MODEL_ZOO.md](https://github.com/facebookresearch/sapiens2/blob/main/docs/MODEL_ZOO.md) 下载，放到家目录下的 `sapiens2_host/seg/sapiens2_<size>_seg.safetensors`。

下面的命令在 `sapiens2` 容器里、仓库的 `sapiens/dense` 目录执行。

```bash
docker exec -it sapiens2 bash
cd sapiens2/sapiens/dense
```

## 启动命令

### Sapiens2 FP16 BW1100 1x throughput

`tools/deployment/torch_optimization.py` 在导出后执行 `torch.compile(model, mode="default")`。日志里的 `Average time per sample` 是每张图的毫秒数，吞吐 = `1000 / 该毫秒数`。

把 `0.4b` 换成 `0.8b`、`1b` 或 `5b`。`--max-batch-size` 就是 batch。

```bash
HIP_VISIBLE_DEVICES=7 python tools/deployment/torch_optimization.py \
  configs/seg/shutterstock_goliath/sapiens2_0.4b_seg_shutterstock_goliath-1024x768.py \
  --checkpoint "$HOME/sapiens2_host/seg/sapiens2_0.4b_seg.safetensors" \
  --shape 1024 768 \
  --fp16 \
  --max-batch-size 8 \
  --output-file sapiens2_0.4b_seg_fp16_bs8.pt
```

### Sapiens2 BW1100 1x image

这条命令读真实图片并保存分割叠加图，不算吞吐，也不是上面的 FP16 计时。仓库里的 `demo/data` 自带样例图，`--input` 也可以换成自己的图片目录。结果写到 `seg_vis/`，一张图一份左右拼接的可视化。

```bash
HIP_VISIBLE_DEVICES=7 python tools/vis/vis_seg.py \
  configs/seg/shutterstock_goliath/sapiens2_0.4b_seg_shutterstock_goliath-1024x768.py \
  "$HOME/sapiens2_host/seg/sapiens2_0.4b_seg.safetensors" \
  --input ../../demo/data \
  --output seg_vis \
  --save_pred
```
